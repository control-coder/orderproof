# 本地四页面演示运行

仅限本机单用户；数据库和 Redis 监听 Docker 映射的回环随机端口，应用默认回环 18080。不在公网暴露；不要上传未经许可的真实敏感数据。

在 `conda datalab`、Python 3.12 和 Node.js 环境下，从仓库根目录执行：

```powershell
conda activate datalab
python -m pip install --no-build-isolation -e .
npm.cmd ci --prefix frontend --no-audit --no-fund
npm.cmd run build --prefix frontend
# 首次需构建专用镜像；可按“固定分析运行”文档指定经核实的镜像源。
docker build -t datalab-executor:py312-v1 -f scripts/executor/Dockerfile .
python -B scripts/local_services.py start
python -B scripts/serve.py
```

打开 `http://127.0.0.1:18080`。按数据工作台→分析任务→报告详情→项目记忆操作；无确认口径的任务会停在等待边界。提交候选记忆后须由用户明确确认，再到报告详情选取已确认版本并继续。应用进程 Ctrl+C 退出；专用数据库和队列可由 `python -B scripts/local_services.py stop` 停止，停止操作保留数据库卷和本机配置。勿打印或提交忽略目录 `artifacts/local/runtime.json`；若已有配置需要恢复，重新运行 start，勿重复生成凭据。若 18080 端口被占用，请先排查占用者，不盲目关闭其他进程。

回归：`python -B scripts/test_app.py` 实际运行真实服务集成；`node frontend/tests/browser-flow.mjs` 使用本机 Edge 的 Playwright；前端构建使用上述 npm 命令。模拟角色不等同真实模型。Docker 镜像名称、Node 版本和本机端口按实际环境核对；源站不可用时可显式传入经过核实的 `--build-arg PYTHON_IMAGE=...`，不静默改变镜像来源。
