# 模型配置与一键切换

三角色可使用 MiMo（默认）或 DeepSeek 的 OpenAI 兼容 `chat/completions` 接口，也可切回不调用模型的固定演示。配置位于仓库根目录 `.env`（已被 Git 忽略），模板为 `.env.example`。

## 填写密钥

在本机编辑 `.env`，只填写 `DATALAB_MIMO_API_KEY` 或 `DATALAB_DEEPSEEK_API_KEY`；也可以不写入文件，改为进程环境变量注入（环境变量优先）。不要把密钥粘贴到聊天、日志或提交中。接口与页面只显示“是否已配置”，不回显密钥。

默认端点与模型名写在 `.env` 中，可按供应商控制台实际值修改：

| 供应商 | BASE_URL | MODEL |
| --- | --- | --- |
| mimo | `https://api.xiaomimimo.com/v1` | `mimo-v2.6-flash` |
| deepseek | `https://api.deepseek.com` | `deepseek-flash` |

端点必须为 HTTPS。若供应商不支持 `response_format=json_object`，将对应 `*_JSON_MODE` 设为 `false`，提示词仍要求只输出 JSON。

## 切换

```powershell
python -B scripts/switch_model.py            # 查看当前供应商及是否已配置密钥
python -B scripts/switch_model.py deepseek   # 切到 DeepSeek
python -B scripts/switch_model.py mimo       # 切回默认 MiMo
python -B scripts/switch_model.py guided     # 固定三角色演示，不调用模型
```

网页顶部“三角色模型”下拉框调用 `PUT /api/model` 做同样的切换。切换只改写 `.env` 中 `DATALAB_MODEL_PROVIDER` 一行；新建任务立即生效，已创建任务仍使用创建时记录的模型；worker 每个任务重新读取 `.env`，补充密钥或切换后无需重启。没有 `.env` 时系统保持固定演示。

## 调用边界

- 当前供应商未配置密钥时，模型任务在创建时返回 400，不静默降级为固定演示。
- 每个任务的调用次数、总 token 和总时长受 `DATALAB_MODEL_MAX_*` 限制；单次请求超时取供应商 `*_TIMEOUT` 与剩余预算的较小值，不自动重试。Reviewer 另用 `*_REVIEWER_MAX_OUTPUT_TOKENS`（默认 2048）与 `*_REVIEWER_TIMEOUT`（默认 60 秒）；未写这两行时使用默认值。
- Planner 只决定分析类型、分组和期间；数据版本、指标版本和纳入状态由服务端交接固定。Analyst 代码只在无网络受限容器中运行；成功仍以独立 SQL 参考核验为准，Reviewer 不能批准核验失败的结果，只在核验通过后判断计划是否读对问题，驳回交 Planner 复核。
- 发送给模型的是问题、数据概况（聚合统计）与已确认口径，不发送订单明细；表格文本在提示中声明为数据而非指令。
- Planner、Analyst 调用异常或输出不符合契约时任务以 `MODEL_ERROR` 失败；Reviewer（及驳回后的 Planner 复核）失败时跳过审查、记录原因并采用已通过独立核验的结果。错误信息不含密钥或响应原文。
