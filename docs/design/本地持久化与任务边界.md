# 本地持久化与任务边界

首版是单用户回环受控演示，而不是公网多租户平台。FastAPI 验证项目归属、Host 和写入 Origin/客户端标识；标识不是登录凭据。若未来对公网提供服务，必须先补正式身份认证、授权、CSRF 防护、传输保护和部署审计，不能直接开放当前端口。

PostgreSQL 是数据版本元信息、业务 Memory、任务快照和产物索引的权威；规范化 CSV 与只读执行产物放本机忽略目录。Redis/Celery 仅传任务 ID，重复投递通过数据库原子租约去重；人工口径确认保存在数据库，释放 worker，并在确认后从计划边界重新排队。超时租约标记失败并保留证据，不模拟中途恢复任意 Python。worker 以行锁检查末端取消，执行期通过心跳检查取消；终态不能由旧 worker 覆盖。报告引用数据版本、口径快照、代码、执行清单、核验记录和结果产物 ID。

分析容器无网络、非 root、只读输入与根文件系统，CPU/内存/PID/时间/输出限制由宿主 Docker 控制；应用 API、队列和数据库自身**不**运行在该分析沙箱中。仅可信服务端可调用执行器；本地目录和随机本机配置不提交。角色领域边界是显式上下文和工具权限，固定角色后端不等同真实模型代理；前端的“自然语言问题”只作为意图记录，真正执行类型由受限选项确定。

运行模式不是零信任：若可信宿主进程或本机账户被攻陷，回环地址和普通容器隔离不能保证数据安全。不可将这些防护表述为高风险数据的全面保障。
